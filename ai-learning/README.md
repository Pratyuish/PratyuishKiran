# AI Learning for Platform, SRE & Engineering Leadership

This learning track is designed to build practical, interview-ready Generative AI and Agentic AI skills on top of an existing Platform Engineering, SRE, DevOps, Kubernetes and AWS background.

## Goal

Build enough hands-on capability to credibly discuss, design and demonstrate production-oriented AI systems without claiming commercial AI experience that has not yet been gained.

Target positioning:

> Engineering / Platform / SRE Leader with hands-on Generative AI, RAG, Agentic AI, MCP and LLMOps project experience.

## Learning Principles

- 20% theory
- 60% implementation
- 20% architecture and interview preparation
- Build before adding a skill to the resume
- Prefer production-oriented use cases over generic chatbot demos
- Document architecture, trade-offs, security, observability and failure modes

## Core Modules

1. LLM & Generative AI Fundamentals
2. Prompt Engineering & Structured Outputs
3. Python for AI Applications

## Resume Rule

Only list technologies after completing enough hands-on work to explain:
- what was built,
- how it works,
- trade-offs,
- security implications,
- reliability considerations,
- observability,
- cost,
- and how it would be productionized.
